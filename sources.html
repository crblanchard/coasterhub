Stats by field

On the site is how many coasters have the field filled in now. Open source counts the ones where an open source has it without citing RCDB, plus fair coasters, which never came from RCDB. Agree and Differ compare the open value with the current one (numbers within 5%). New is a value only the open source has. To choose counts the coasters where the site and the sources disagree and you haven’t picked yet (model names aren’t counted: every source names models its own way).
