You’ll need the password

Adding to the shared database is held behind a password for now. Ask Carter for it, or send him what’s missing and he’ll add it.

New coaster

Pick the park first — the duplicate check runs against what’s already there. Only the name and park are required.

New park

Add the park first if the coaster you want isn’t at anywhere listed. Coordinates come later — the geocoder in /edit puts it on the map.

US parks are “<State>, US”. Everywhere else is just the country.
